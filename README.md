# AgroVision - Potato Disease Detection

AgroVision-Potato-Disease-Detection is a full-stack AI-powered mobile application that detects potato leaf diseases (Early Blight and Late Blight) using a Convolutional Neural Network (CNN) built with TensorFlow/Keras. The system includes data preprocessing, image augmentation using ImageDataGenerator, and model training on a labeled dataset. The trained model is served using a FastAPI backend (running locally) and integrated with a Flutter mobile application for real-time disease prediction.

---

## Overview

This project provides an end-to-end pipeline for automated potato plant disease detection. It combines deep learning, backend API services, and mobile application development to deliver real-time predictions from user-uploaded images.

---

## Features

- CNN-based image classification model
- Detection of Early Blight and Late Blight diseases
- Data preprocessing and augmentation
- FastAPI backend for model inference (local server)
- Flutter mobile application for real-time prediction
- End-to-end AI workflow (training → local deployment → mobile integration)
